E-Commerce Microservices Demo Angular Frontend with UI Testing Scaffolding

This Angular application demonstrates a minimal GUI for interacting with three Spring Boot microservices:

  • Customer Service - Port 8081
  • Inventory Service - Port 8082
  • Order Service - Port 8083

The application includes scaffolding for the following testing frameworks:

  • Jest - Unit testing
  • TestCafe - End-to-end testing
  • Cucumber - BDD testing
  • Selenium - End-to-end testing

Note: Make sure all three microservices are running before navigating to the data views.
